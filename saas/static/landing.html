How it works

Three passes, one graph.

Code structure — free

Tree-sitter parses classes, functions, imports, call graphs and inline comments. Local, deterministic, no LLM. SQL gets special treatment: tables, views, foreign keys and JOINs extracted deterministically. A code-only corpus never touches Pass 3.

Video & audio — local

Transcribed with faster-whisper, with the prompt seeded by your top god nodes so the transcript stays on-domain. Transcripts are cached; re-runs skip processed files.

Docs, papers, images — semantic

Parallel subagents read batches and emit JSON fragments — nodes, edges, group relationships — merged into one graph. This is the only pass that spends tokens, and only if you configure a backend.

Communities without embeddings

Communities come from the Leiden algorithm — nodes grouped by edge density. The semantic similarity edges already in the graph shape the clusters directly: the structure is the similarity signal. No embedding step, no vector database.

Confidence you can audit

EXTRACTEDexplicit in the source — an import, a direct call. Confidence 1.0.
INFERREDdeduced by resolution, on a discrete rubric: 0.95 near-certain → 0.55 speculative.
AMBIGUOUSuncertain — flagged in GRAPH_REPORT.md for human review.

The hosted product

The same graph, as a workspace your whole team can open.

This deployment ships the hosted surface: one origin serving the web workspace, a JSON API for your own tooling, and an MCP endpoint your IDE already speaks — scoped per workspace, gated per key.

IDE & agent ready

MCP Streamable HTTP on /mcp with 10 tools — query_graph, shortest_path, god_nodes… Point Cursor, VS Code, Claude Code or Codex at it with one JSON snippet.

Workspaces & keys

One graph per workspace, members with roles, and gf_… API keys stored hashed, shown once, revocable. A key can never cross tenants — asking it to is a 403.

Scales past one laptop

Parsed graphs live in a bounded LRU invalidated by content fingerprint, so 50 tenants don't mean 50 graphs in RAM and a graphify update lands without a restart.

Themed end to end

One token file drives the web app, the canvas and — soon — the exported graph.html and your extension's webview. Re-brand is one edit.
